# Judges

Other interrogators put to the same thirty-four pairs as the game.

- `prompt.txt`: the prompt given to a chat model, all thirty-four pairs with the sides drawn at random (seed 20261111); `key.txt`: which side was the human's, one letter per pair.
- `chatgpt-1.txt`: ChatGPT's reply, 11 November 2026: 34 of 34 right; it recognised all thirteen novel openings as published text, so that stage was recall; the other twenty-one it judged, and was never wrong.
- `set-A.txt` to `set-F.txt`: the same texts as six files for a detector, one sentence per line: A and B are Turing's questions (human, machine); C and D the novels (novelists, machine); E and F the diaries (human, machine imitating). The letters say nothing to the detector.
- `human.txt` and `machine.txt`: the thirty-four human lines and the thirty-four machine lines as two files, nothing else in them. Pangram, 11 November 2026, as reported by the author: `human.txt` judged 100 per cent human-written; `machine.txt` judged 70 per cent AI-written. Both right; the detector had no doubt about the humans and some doubt about the machines, and the file it doubted is one third imitation (the diaries) and one third period pastiche (the novels).
