# The Other Chain — note for the author

1. Look first at `screenshot-l1-zipped.png` (a first-timer's ladder: the rails bow at G–G, pinch at T–C), then `screenshot-copy-done.png` and `screenshot-end.png`.
2. Every number is in the `CONFIG` block at the top of `mechanism.js`, the only copy of the mechanism: the letter's helix numbers (p. 737), the bump/dent pattern of each base, the piece lengths (our units), the ladder sizes and the fork's pace. Edit, run `node calibration.js` (27 checks), then `python3 build.py`, which refuses to finish if the embedded mechanism differs from the file.
3. What we were least sure about: (a) the bump/dent patterns are standard chemistry for the keto forms, not printed in the letter, and the game uses the letter's two contacts per pair (G–C has a third); (b) the copy goes beyond this letter (it follows the second 1953 letter), and the About screen says so; (c) whether strangers read the bumps and dents on the tray before the first zip or only learn them from it, which only real players can tell.

This game has had the builder's review only: screenshots and a scripted browser session at 380 px. It has not been played by real strangers, and the 3–5 minute length is an estimate. The letter was read from a scan; its numbers were checked against published transcriptions.
