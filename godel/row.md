| **Gödel's Endgame** | Gödel (1931), *Monatshefte für Mathematik und Physik* 38:173–198. On formally undecidable propositions of Principia Mathematica and related systems, as Hilbert's honest printing machine in a Vienna Werkstätte cabinet: type sentences on four keys (NOT, PRINTS, TWICE and a box), find that no sentence can contain itself, learn what TWICE copies, and fill the box until the sentence talks about itself: "the machine never prints this very sentence". The honest machine can never print it, so it is true; Machine II gets the same trick; the machine can't print that it is honest; and the keys turn into Gödel's numbers. | [play](https://steffenhuck.github.io/paper-to-game/godel/godels-endgame.html) · [memo](godel/memo.md) |
