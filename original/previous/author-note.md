# The Original or the Copy — note for the author

1. Look first at Campaign 1's result after a "much more + tougher" choice (+13.8 points). That is where the game lands its main finding. Check whether it reads as the paper's Fig. 5 rather than as an exaggeration: it sits at the edge of the figure's axis.
2. Every number is in the `CONFIG` block at the top of `mechanism.js`, the only copy of the mechanism, and each line is tagged with its table or figure. The Act 1 values are read off Fig. 3. Edit there, run `node fidelity.js`, then `python3 build.py`. The build refuses to run if the embedded mechanism differs from the file.
3. I was least sure about two things. One is the per-country Fig. 3 read-offs (about ±0.3) and the one-line reasons I paraphrased for each country. The other is leaving out a "talk less" option. With that option, the straight-line model would make "quiet and tough" shrink the radical right by about 12 points, which the paper's text never claims. The "more open is safe" result rests on the interaction term alone, and the game says so.

This game has had the builder's review only: screenshots and a scripted browser session at 380 px. It has not been played by real strangers, and the four-minute length is an estimate.
